# Customer-Shopping-Behavior-Analysis

# 📌 Project Overview

This project focuses on analyzing customer shopping behavior data to uncover meaningful business insights and support strategic decision-making.
The analysis was performed on a dataset containing 3,900 customer purchase records with demographic details, shopping patterns, subscription information, ratings, and purchase behavior.

The project includes:

Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Feature Engineering
SQL Integration using PostgreSQL
Data Visualization
Business Insights & Recommendations

# 🎯 Objectives
Analyze customer purchasing behavior
Identify high-value customer segments
Understand the impact of subscriptions and discounts
Discover revenue trends based on demographics
Generate business recommendations using data insights
🛠️ Technologies Used
Python
Pandas
NumPy
PostgreSQL
Jupyter Notebook
Power BI 

# 📂 Dataset Information

The dataset contains:

Customer demographics
Purchase amounts
Product categories
Review ratings
Subscription status
Shipping preferences
Discount usage
Payment methods
Dataset Summary
Total Records: 3,900
Columns: 18
Missing Values: 37 (Review Rating column)

# ⚙️ Data Preparation Process
1. Data Loading

Imported the dataset using Pandas.

2. Data Exploration

Performed structure checks, data type verification, and summary statistics.

3. Missing Value Handling

Filled missing values in the Review Rating column using median imputation.

4. Feature Engineering

Created:

Age Groups
Purchase Frequency Categories
5. Database Integration

Connected the processed dataset with PostgreSQL for SQL-based analysis.

# 📊 Key Insights
Revenue by Gender
Female customers generated slightly higher revenue than male customers.
High-Value Discount Users
Some high-spending customers actively used discounts, indicating smart shopping behavior.
Top-Rated Products

Highly rated products included:

Blouse
Dress
Shirt
Shipping Preferences
Customers using Express Shipping spent approximately 12% more per transaction.
Subscription Impact
Subscription customers showed:
Higher spending
Better loyalty
Increased repeat purchases
Customer Segmentation

Customers were categorized into:

Loyal Customers

New Customers
